How updates work

We check the public GotSport schedule on Saturday and Sunday at 5 PM Pacific.

Only completed matches count. Canceled, postponed and unscored fixtures are excluded.

If GotSport blocks access or the response cannot be verified, the last confirmed table remains published.

Manual results import

Have updated match results? Import a GotSport-style text export or the tracker JSON. Review the standings locally, then download a JSON file to submit for publication.

Imports affect only your browser until the exported JSON is committed to the repository. No public submissions or server storage.
